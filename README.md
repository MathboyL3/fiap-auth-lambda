# fiap-auth-lambda

Function Serverless (AWS Lambda, Node.js/TypeScript) de autenticação por **CPF → JWT**, exposta via **API Gateway**. Parte do Tech Challenge Fase 3 (SOAT/FIAP).

> Provisionado via Terraform contra **LocalStack** (AWS local). Portável para AWS real.

## Tecnologias
- Node.js / TypeScript (AWS Lambda)
- AWS API Gateway + Lambda + Secrets Manager (via LocalStack)
- Terraform
